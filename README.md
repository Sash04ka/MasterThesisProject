# Master Thesis – Application of Machine Learning in Option Pricing

This repository hosts the practical implementation accompanying the master's thesis of Aleksandr Shabanov. The research focuses on leveraging neural networks, specifically Multilayer Perceptrons (MLPs), to price exotic options via the Volatility Feature Approach (VFA), utilizing synthetic data generated from the Bates stochastic volatility model with jumps.

---

## 📁 Project Structure

- `code/`  
  Python scripts for data simulation, model training, evaluation, and benchmarking.

- `notebooks/`  
  Jupyter notebooks for exploratory data analysis, model experimentation, and visualization.

- `data/raw/`  
  Raw synthetic datasets generated by simulation scripts.

- `data/processed/`  
  Preprocessed and cleaned datasets ready for model consumption.

- `results/`  
  Output files including evaluation metrics, plots, and comparison reports.

- `models/`  
  Serialized neural network models and scalers saved after training.

- `logs/`  
  Logs capturing training progress and experiment details.

---

## 🎯 Thesis Objectives

- Generate comprehensive datasets of exotic options (Asian, Barrier, Lookback) using the Bates model with jumps.
- Engineer volatility smile features for enriched model input representation.
- Develop and train MLP-based neural networks for pricing these exotic options.
- Benchmark neural network pricing accuracy and computational efficiency against classical Monte Carlo methods.

## 🔎 Dataset Column Description

| Column  | Description                                              |
|---------|----------------------------------------------------------|
| `K`     | Strike price of the option                               |
| `T`     | Time to maturity (in years)                              |
| `barrier` | Barrier level (only applicable for barrier options; NaN otherwise) |
| `type`  | Option type: `"asian"`, `"barrier"`, or `"lookback"`    |
| `price` | Simulated option price computed as discounted payoff    |
| `sigma_*` | Volatility smile features at various moneyness and maturities (e.g., `sigma_080_1m`) |

## 🚀 Getting Started

1. Clone this repository  
2. Install dependencies (see `requirements.txt`)  
3. Generate datasets by running `generate_dataset.py`  
4. Train models via `train_models.py`  
5. Evaluate performance using `compare_mc_vs_mlp_all.py`  
6. Visualize results through `evaluate_models.py` or notebooks
